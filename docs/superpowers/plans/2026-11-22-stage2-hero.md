# Stage 2 — Hero and CTAs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hero with the chosen headline, availability badge, audience-ordered CTAs, reassurance and recruiter lines, and an honest proof strip, with no layout shift.

**Architecture:** All facts live in `src/content/profile.ts`; unknown facts are `null` and render honestly or not at all. The existing pre-paint inline script also sets `data-audience` on `<html>`; CSS shows the matching CTA pair. Static Astro components, no framework.

**Tech Stack:** Astro 7, Tailwind v4, Vitest, Playwright (+ axe). Builds on Stage 1 (`e90e8ba`).

**Spec:** `docs/superpowers/specs/2026-11-22-stage2-hero-design.md`

## Global Constraints

- Headline, verbatim: `WhatsApp AI agents for businesses that can't afford to miss a message.`
- Supporting sentence: `I also build automations and web apps that save your team hours.`
- Reassurance, verbatim: `Replies within 12 hours · Pay via M-Pesa, Wise or Payoneer · Weekly progress demos`
- Badge: unknown capacity → `Booking projects for December · EAT (UTC+3)`; capacity N → `Available for N projects in December · EAT (UTC+3)` (N = 1 → "1 project").
- CTA copy: local `Chat on WhatsApp` (primary, `WHATSAPP_URL`) + `See my work` (`#work`); international `Book a 15-min call` (primary, `BOOKING_URL`) + `Email me` (`mailto:` EMAIL).
- Recruiter line: `Hiring?` + `Download CV` (link only when `cvUrl` set, else plain text `CV coming soon`) + `View GitHub` (`GITHUB_URL`).
- Proof items: `Diploma in Software Engineering`, `BSc Electronics & Computer Engineering (in progress)`, `N agents shipped` (omitted when null), client quote (omitted when null).
- Never invent facts; never hide WhatsApp (sidebar + bottom bar keep it for international visitors).
- One commit for the stage after Melvine approves screenshots. Spacing on the 8px grid; tap targets ≥ 44px; AA contrast.

## Review Focus

1. **Timezone edge values** (`UTC`, `Etc/GMT-3`, `Asia/Dubai` = UTC+3 but not Africa, `Intl` throwing) → only `Africa/*` is local; errors fall back to local without a JS error. Test in Task 1 (unit) and Task 2 (throwing Intl).
2. **Kenyan visitor on a VPN/European timezone** → WhatsApp still reachable without scrolling (sidebar on desktop, bottom bar on mobile). Test in Task 3.
3. **Hidden CTA pair announced to screen readers** → the non-matching pair is `display: none`, not just visually hidden. Test in Task 3.
4. **Narrow phones (320px) and long lines** (badge, reassurance) → no horizontal scroll. Test in Task 4.
5. **No-JS visitors** → local pair shows, nothing broken. Test in Task 2.
